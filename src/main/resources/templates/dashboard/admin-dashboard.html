TextBee.dev API Configuration & Deployment Environment

Environment Configuration

To configure or update TextBee.dev SMS credentials in production (e.g. Render), set the following environment variables: 

TEXTBEE_API_KEY=your_actual_textbee_api_key
TEXTBEE_DEVICE_ID=your_device_id
TEXTBEE_ENABLED=true
PORT=10000
Security Compliance:

API keys and secret tokens are never sent to web browsers, never rendered in HTML client code, and never committed to version control.
